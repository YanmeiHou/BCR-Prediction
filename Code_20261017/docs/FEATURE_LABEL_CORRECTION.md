# Feature identity status

The earlier working package contained author-requested replacements of SSPO, PLEK2,
CCDC188 and NHLH1 with TOP2A, PGM5, CHRDL1 and DNAH8, based on plotted ranks.
That correspondence has not been independently established from matrix feature IDs
and the fitted selector objects. The full RF table contains the proposed target
names elsewhere, creating collisions if substitutions are applied indiscriminately.

This release uses the original feature lists and coefficients for the saved-record
audit. It does not rename features to make the RF/LASSO intersection equal four
preselected genes. The four candidate genes used for subsequent analyses and the
three predictors retained in the historical final RF are documented separately.
Resolve identities before claiming that discovery reproduced the four-gene panel.
